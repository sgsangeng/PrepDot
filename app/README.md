# PrepDot Frontend Skeleton

This is a dependency-free MVP frontend prototype for PrepDot.

On macOS, double-click `../PrepDot.command` to start the local preview and open it in your browser.

Open `index.html` directly in a browser, or run a static server from this directory:

```bash
python3 -m http.server 5173 --bind 127.0.0.1
```

Current scope:

- Today plan page
- Knowledge base page
- Card library page
- Review session page
- Lightweight graph page
- Settings page with API Key state
